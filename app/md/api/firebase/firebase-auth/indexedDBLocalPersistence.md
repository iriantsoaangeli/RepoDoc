# indexedDBLocalPersistence

*Constante — `firebase/auth`*

**Import**
```ts
import { indexedDBLocalPersistence } from 'firebase/auth'
```

**Signature**
```ts
const indexedDBLocalPersistence: Persistence
```

**Description**
Mode de stockage de la session dans IndexedDB : l'utilisateur reste connecté entre deux lancements de l'app. C'est le choix fiable dans la WebView d'un APK Capacitor. À passer dans `initializeAuth`.
