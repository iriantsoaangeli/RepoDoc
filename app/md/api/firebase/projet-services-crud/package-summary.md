# Package `@/services/crud`

Fichier `src/services/crud.ts`. Opérations valables pour n'importe quelle collection créée avec `makeCollection`.

| Nom | Nature | Description |
|---|---|---|
| [`Col<T>`](Col.md) | Type | Type de l'objet renvoyé par `makeCollection<T>`. |
| [createOne](createOne.md) | Fonction | Crée un document. |
| [listMine](listMine.md) | Fonction | Renvoie les documents de l'utilisateur connecté (`owner == uid`), du plus récent au plus ancien. |
| [getOne](getOne.md) | Fonction | Lit un document par son id. |
| [updateOne](updateOne.md) | Fonction | Modifie les champs donnés. |
| [deleteOne](deleteOne.md) | Fonction | Supprime un document. |
