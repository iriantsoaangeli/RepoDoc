# FieldValue

*Type — `firebase/firestore` · Types*

Type des valeurs spéciales renvoyées par `serverTimestamp()`, `increment()`, `deleteField()`, `arrayUnion()` et `arrayRemove()`. Elles ne sont pas des données : ce sont des **instructions** pour le serveur.
